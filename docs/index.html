Installation notes

For best results, use Copy formatted signature and paste into the email client's signature editor. If images do not appear after pasting, confirm the logo, handwritten-signature image, and LinkedIn icon are hosted at HTTPS URLs that open for the intended recipients without a sign-in prompt.

Telephone numbers are generated as tel: links, so supported phones and calling apps can open the dialer from the signature.

Email clients handle HTML differently. This generator uses table-based layout and inline styles because they are more dependable across Outlook, Apple Mail on iPhone, and Thunderbird than modern web layouts.

SharePoint can be used as the source location only if each image has a reliable direct file URL and the sharing permissions allow the image to load. Test the copied signature by sending it to internal and external recipients before rollout.

Keep the final signature lean. Large images and long disclaimers can make email threads difficult to read, especially on phones.
